# Evolution Marketplace Archive (2014–2015)

## Overview
This directory contains research fixtures, profiling metadata, and extraction pipelines for the historical Evolution darknet market archive.

## Primary Roles
- Marketplace behavioral profiling (listing frequency, price distributions, feedback cadence).
- Temporal activity distributions for vendor operational hours.
- Graph co-occurrence analysis (shared PGP keys and Bitcoin wallet reuse).
- Synthetic simulator calibration parameters.
